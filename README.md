# Perjalanan Kita — untuk Damaraa

Buku perjalanan digital: kue ulang tahun interaktif yang terbuka jadi buku berisi 7 halaman kenangan sahabat.

HTML, CSS, dan JavaScript murni. Tanpa build, tanpa dependency.

## Lihat

Buka `index.html` langsung di browser, atau lewat GitHub Pages.

## Struktur

- `index.html` — seluruh halaman dan animasi
- `img/` — foto kenangan (sudah dioptimasi)
